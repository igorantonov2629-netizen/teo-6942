# Бот «Мой день» для курсантов МИК

Telegram-бот: каждый день сам присылает курсанту пары, кабинеты, меню столовой и дежурного.
Это отдельный проект, он не связан с магазином Teo: у него свой токен, своя база и свой процесс.

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather) и получи токен.
2. Узнай свой числовой Telegram ID (например, у @userinfobot).
3. Настрой окружение:
   ```bash
   cd myday-bot
   cp .env.example .env      # впиши BOT_TOKEN и ADMIN_IDS
   bun install
   bun run check-privacy     # проверка, что данные курсантов скрыты
   bun run start
   ```
Бот работает через long polling, поэтому ему не нужны домен, вебхук или открытый порт.
Чтобы бот работал круглосуточно, запускай его через pm2 или systemd, например
`pm2 start "bun run start" --name myday-bot`.

## Что умеет

**Курсант:** /start → курс → группа. Внизу экрана всегда 7 кнопок: Сегодня, Завтра, Неделя, Меню, Дежурный, Заказать конспект, Настройки.

**Автоматические рассылки** (время Владивостока, меняется в `TIMEZONE`):

| Время | Что приходит |
|---|---|
| 7:00 (Вс — 8:00) | пары, кабинеты, завтрак, дежурный |
| за 10 мин до пары | какая пара и где |
| 13:15 (Вс — 12:25) | меню обеда |
| 17:15 | меню ужина |
| 19:00 | расписание на завтра с заменами; в субботу — «завтра пар нет» |
| сразу | замены, объявления, появившееся или исправленное меню |

Верхняя и нижняя неделя: неделя с 9 ноября 2026 года — верхняя, дальше недели чередуются автоматически (`UPPER_WEEK_START`).

**Админ** (ID из `ADMIN_IDS`). Команды работают и на кириллице, и на латинице:

| Команда | Что делает |
|---|---|
| `/меню` (`/setmenu`) | меню на день: «Завтрак: …», «Обед: …», «Ужин: …» одним сообщением. Если первая строка «завтра», меню сохраняется на завтра. Меню можно прислать и без команды. |
| `/дежурные` (`/duties`) | выбрать месяц и прислать список «1 Борт / 2 Ельцов …»; бот покажет дни без дежурного |
| `/замена` (`/sub`) | группа → дата → пара → отменить, заменить или вернуть как в расписании |
| `/объявление` (`/announce`) | текст или фото, аудитория, отметка «Важное» (приходит всем и закрепляется) |
| `/реклама` (`/ad`), `/ads` | рекламный пост по расписанию; список и остановка постов |
| `/статистика` (`/stats`) | пользователи по курсам и группам, охват и клики рекламы |
| `/cancel` | прервать текущий диалог |

Бот сам предупреждает админа, если до 7:00 не прислано меню, а также в 12:00, если на ближайшие 3 дня не указан дежурный.
Список дежурных на ноябрь 2026 из концепта загружается автоматически.

**Правила рекламы:** не больше одного поста в день на человека; только с 9:00 до 21:00; всегда отдельным сообщением с пометкой «Реклама» и полем erid; считаются доставки и уникальные нажатия.
Кнопка в рекламе сначала засчитывает нажатие, потом бот присылает ссылку. Так клики можно посчитать без своего веб-сервера.

**Заказ конспекта:** предмет (из расписания группы или «Другое») → тема → страницы → тип (50 или 75 ₽ за страницу) → кнопка открывает чат @sanekhelper с готовым текстом.
Данные заказа в базе не сохраняются.

## Приватность данных курсантов

- О курсанте хранится только `chat_id`, курс, группа, флаг уведомлений и время регистрации. Имена, username, телефоны и тексты сообщений не хранятся.
- У бота нет HTTP-сервера и API, поэтому базу нельзя получить по сети.
- Файл базы создаётся с правами `600`, папка — с правами `700`. `.env` и `data/` исключены из git.
- Админ-команды и админ-кнопки проверяются по числовому Telegram ID. Остальным бот отвечает так же, как на неизвестную команду.
- Статистика показывает только общие числа, без ID пользователей.
- Бот отвечает только в личных сообщениях. Незавершённые диалоги удаляются через сутки.
- Токен вырезается из всех сообщений об ошибках.

`bun run check-privacy` проверяет всё это на реальной базе.

## Расписание

Данные лежат в `src/schedule-data.ts`. Они вручную перенесены из PDF учебной части, осенний семестр 2026–2027.
Ячейка вида `"TG/VM"` означает: на верхней неделе TG, на нижней VM.
В новом семестре достаточно заменить `LESSONS` и `TIMETABLE`.
Тесты проверяют, что у всех 17 групп по 6 дней и все коды занятий известны.
